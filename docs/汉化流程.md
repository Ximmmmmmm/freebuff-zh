# 汉化流程说明

Freebuff Desktop 是打包产物（Electron asar + 前端 bundle），汉化在**不重新构建源码**的前提下完成：
对打包后的 JS/HTML 做字符串替换。核心是 `dict.json` 翻译词典，`tools/` 提供提取与核查脚本。

## 词典结构（dict.json）

| 类型 | 作用 | 匹配方式 |
| --- | --- | --- |
| `exact` | 全局精确替换 | `"English"`（双引号字符串字面量） |
| `template` | 反引号模板字面量 | `` `English ${...}` `` |
| `code` | 多 token 逐字片段 | 原样替换（用于复数、属性名等） |
| `pattern` | 仅界面属性上下文 | `children:"X"` / `label:"X"` / `title:"X"` / `placeholder:"X"` / `"data-tooltip":"X"` / `"aria-label":"X"` / `confirmLabel:"X"` |

应用顺序：`pattern` → `code` → `exact` → `template`（`tools/apply.js`）。幂等：重复运行不会重复翻译。

## 典型工作流

```
扫描残留 ──▶ 定位原文 ──▶ 写入词典 ──▶ 重新构建 ──▶ 核查
```

### 1. 扫描残留英文

```bash
# 渲染 bundle
node tools/extract.js   <bundle> [--all]        # 候选字符串（按出现次数排序）
node tools/leftover.js  <bundle> > work/leftovers.txt   # 词法扫描剩余英文
node tools/prose.js     <bundle>                # 多词英文片段（含拼接碎片）
node tools/uipos.js     <bundle>                # 仍处于界面属性位置的英文
node tools/attrs.js     <bundle>                # UI 属性值里的英文

# 主进程（先解包 app.asar 或直接用 backup/asar-extracted）
node tools/mainscan.js  <dir>                   # 主进程残留英文扫描
node tools/menuscan.js  <dir>                   # label/title/message/detail 等
```

### 2. 定位原文（确认写法，避免字节不匹配）

```bash
node tools/context.js   <bundle> "string"       # 上下文窗口
node tools/context2.js  <bundle> "word"         # 精确双引号出现位置
node tools/exact.js     <bundle> <search> [max] # 打印完整字面量（模板/引号）
node tools/tctx.js      <file> <substring> [max]# 反引号模板上下文
node tools/count.js     <file> <word> ...       # 出现次数统计
```

### 3. 写入词典

- **版本迁移（新 bundle 变量改名）**：`node tools/remap.js <新bundle> [--write]` ——
  按英文锚文本定位原 template 条目，自动把 `${...}` 插值表达式迁移到当前构建；
  输出 RENAMED / AMBIGUOUS / MISSING 分类报告，只有 RENAMED 会被写回。
- 少量新增：直接编辑 `dict.json` 对应分区。
- 批量新增：`node tools/addl10n.js <bundle> [--dry]` —— 内置一批[原文, 译文]对，
  从 bundle 中按特征子串提取完整模板原文（保证破折号/引号逐字节一致），合并进词典。
- 改完自查：`node tools/lint_dict.js` —— 结构 / 重复键 / `${...}` 占位符一致性
  （CI 也会跑同一检查）。

### 4. 重新构建并安装

```bash
bash build.sh          # 原版 + 词典 + 补丁 → output/（补丁语法校验 + 产物自检，防静默失败）
bash apply.sh          # 安装到应用（自动备份）
```

`build.sh` 末尾会运行 `tools/postbuild.js`：断言 `ui/index.html` 带汉化标记、
主 bundle 覆盖率正常、主进程补丁后文件语法合法且含译文哨兵。
任一不过会以非零码中止——这是针对 0.0.70（补丁被静默跳过、产物一直是英文）与
0.0.72（补丁悬空模板导致启动崩溃）两类历史事故的防线。

### 5. 核查

```bash
node tools/audit.js     <bundle> [candidates.tsv]   # 之前收录的候选是否仍为英文
node tools/remaining.js <bundle>                    # 应用词典后剩余英文短语
node tools/filter.js    <leftovers.txt> [minWords]  # 过滤出像用户可见文案的条目
node tools/tpls.js      <leftovers.txt>             # 含插值的未翻译模板
```

## 注意

- 词典 key 必须与 bundle 中**逐字节一致**（含破折号 `—`、省略号 `…`、弯引号 `’` `“”`），
  优先用 `exact.js` / `addl10n.js` 从 bundle 提取原文，不要手抄。
- 有意保留英文：编程语言名、主题名、键盘键名、内部枚举/类型名、库内部错误信息。
